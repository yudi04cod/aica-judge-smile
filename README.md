One warm line for make.fun's "Make the Judge Smile": a single line of at
most 200 characters about a small good thing that happened today — the
stray cat who always ignored me finally headbutted my ankle, then
followed me all the way home like I'd been hired.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–200 characters), and writes the same bytes on every run.
